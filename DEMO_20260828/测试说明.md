# CATIA BOM 导出 DEMO（2026-08-28）

本 DEMO 用于验证以下内容：产品结构、唯一件汇总、总成/零件截图、属性材质、PartBody 材质、名义厚度、包装包络尺寸，以及**质量（kg）**。

## 明天测试步骤

1. 在 CATIA V5 中打开要测试的 `.CATProduct`，并让它成为当前激活窗口。
2. 双击 `运行DEMO.bat`。若双击被系统拦截，可在本目录打开 PowerShell 后执行 `python .\catia_bom_demo.py`。
3. 等待命令窗口显示“DEMO 完成”。输出会生成在 `输出\BOM表`、`输出\零件图片`、`输出\日志`，不会覆盖主工程已有结果。

## 请重点核对

- `BOM汇总` 中每种唯一零件的数量、图片、材质和厚度是否正确。
- `质量(kg)` 是否与 CATIA 的惯性/质量属性一致；没有密度的零件通常会显示 `0` 或失败状态。
- `包络长/宽/高` 是否符合预期。它优先使用 PartBody 惯性主轴下的 Rough Stock 口径，失败时会回退到零件 XYZ。
- 若有失败项，请把同一时间戳的 Excel 和 `输出\日志` 中的日志文件发给我；日志会记录具体零件号和失败原因。

## 运行环境

- Windows + CATIA V5（已启动）
- Python 3.9+，并安装 `pywin32`、`openpyxl`、`Pillow`

可用以下命令检查依赖：`python -c "import pythoncom, win32com.client, openpyxl, PIL; print('依赖正常')"`

若提示“未连接到正在运行的 CATIA”，请双击 `CATIA连接诊断.bat`，并按窗口中的检查项排查；将诊断结果截图发送即可进一步定位。

如果另一台电脑显示“python 不是内部或外部命令”，请安装 64 位 Python 3.9+，安装时勾选 `Add Python to PATH`，然后在命令提示符中执行：`python -m pip install pywin32 openpyxl Pillow`。新版启动器会自动尝试常见 Python 安装路径；找不到时会在窗口中直接提示，而不会闪退。

不使用批处理时，请在本目录打开 PowerShell，运行：`python .\check_catia.py`。它只做 CATIA 连接检查，不会改动 CATIA 或导出任何文件。
